# Генератор штрихкодов (печать этикеток A4)

Превращает список товаров в готовые к печати этикетки со штрихкодом. Один файл
`index.html` — без установки, без сборки, без сервера. Открывается двойным
щелчком.

**Рабочая версия:** [hanzala.com.tr/araclar/barkod-etiket-olusturucu](https://hanzala.com.tr/araclar/barkod-etiket-olusturucu)

<br>

## Что он делает

- **EAN-13 и Code 128.** Введите для EAN-13 двенадцать цифр — контрольная будет
  посчитана сама; введите тринадцать с неверной — инструмент предупредит, а не
  напечатает молча испорченный штрихкод.
- **Листы этикеток А4** (70×37, 105×37, 52,5×29,7, 38×21, 105×74 мм) или свой
  размер в мм для **термопринтера этикеток**. В режиме рулона каждая этикетка
  уходит на отдельную страницу.
- **Столбец количества** — сколько этикеток одного товара напечатать.
- **Столбец старой цены** — зачёркнутая старая цена и процент скидки.
- Четыре раскладки, размер текста, жирный/курсив, скрытие названия или цены.

Никуда ничего не отправляется: введённый список не покидает браузер, сервера
нет.

<br>

## Формат ввода

По одному товару в строке, столбцы разделяются **табуляцией**, **точкой с
запятой** или **вертикальной чертой**:

```
Молотый кофе	8690000000012	45	2
Чай	869000000002	20
Чай со скидкой	8690000000012	20	1	35
```

`название · штрихкод · цена · количество · старая цена` — пустое количество
считается за 1.

Если в строке нет ни одного из трёх разделителей, используется запятая. Запятая
намеренно оставлена на крайний случай: по-турецки цена пишется `145,90`, и от
разделения по запятой цена становилась 145, а количество 90 — пользователь
просил одну этикетку и получал девяносто.

<br>

## Языки

Турецкий, английский, русский, немецкий и арабский — тот же набор, что на
сайте. Переводятся и размеры, и пример списка, и названия листов, и
предупреждения: `52,5×29,7 mm` по-русски становится `52,5×29,7 мм`, а
по-английски `52.5×29.7 mm`.

Арабский располагается справа налево, с двумя исключениями: поле списка товаров
остаётся слева направо и с левым выравниванием (этот список вставляют из
таблицы, столбцы должны сохранять порядок вставки), и то же самое с
предпросмотром этикеток — это печатный вывод, он не должен следовать
направлению страницы.

У каждого языка свой адрес: `index.html?dil=ru`. Ссылка открывается на том же
языке, теги `hreflang` указывают на эти адреса. Если язык не выбран,
используется язык браузера, а если он не из пяти — турецкий.

Пример списка меняется вместе с языком только пока вы сами ничего не ввели —
смена языка никогда не стирает написанный вами список.

<br>

## Как пользоваться

Скачайте `index.html` и откройте двойным щелчком. Штрихкоды рисует
[JsBarcode](https://github.com/lindell/JsBarcode) через CDN, поэтому при первом
открытии нужен интернет.

Чтобы поставить к себе на сайт, скопируйте файл как есть; других зависимостей
нет.

<br>

## Самопроверка

Откройте `index.html?test=1`. Проверяются расчёт контрольной цифры, выбор
разделителя и проверка штрихкода; затем во всех пяти языках проверяется полнота
таблицы перевода и названий раскладок. Если что-то не сходится, заголовок
вкладки станет `HATA:`.
